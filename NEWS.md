# bibliolatam (development version)

- **Initial repository structure and governance**: Scaffolded package infrastructure, dual licensing (GPL-3.0 for code and CC BY-NC-SA 4.0 for scientometric fixtures), and standard BRAN Org community health files.
- **R CMD check hygiene and build flags**: Added `.Rbuildignore` to strip top-level repo metadata (`.github/`, docs, changelog, licensing files) from the R build tarball, preventing non-standard file warnings.
- **Base converter `as_bibliometrix()`**: Introduced canonical converter enforcing the `bibliometrixDB` class contract. Validates essential fields (`AU`, `TI`, `SO`, `PY`), coerces numerical tags (`PY`, `TC`), and injects standard WoS-like tags missing in source files as `NA` without data fabrication.
- **SPELL / ANPAD parser `read_spell()`**: Added resilient parser for Brazilian administration and economics exports (CSV). Supports automatic delimiter detection (`;`, `,`, `\t`), encoding fallback (UTF-8 to Latin-1), and normalizes author names to the standard WoS format (`SOBRENOME INICIAIS; ...`).
- **GUI exporter `export_biblioshiny()`**: Added utility to serialize converted collections into `.RData` files packaging canonical object `M`. Enables direct import via `biblioshiny`'s *Data -> Load bibliometrix RData* menu without script execution.
- **SciELO tabular parser `read_scielo()`**: Added parser for SciELO export files (CSV). Supports Portuguese, Spanish, and English column headers, normalizes multilingual author entries into the standard WoS format (`SOBRENOME INICIAIS; ...`), and maps core metadata (`TI`, `AU`, `SO`, `PY`, `AB`, `DE`, `DI`, `SN`).
- **Robust author normalizer `normalize_authors()`**: Extracted standalone author normalization engine with support for Brazilian generational suffixes (`Junior`, `Filho`, `Neto`, `Sobrinho`), lowercase particles (`da`, `de`, `del`, `van`), and single-name entities.
- **Expanded test coverage for edge cases**: Added dedicated test suites covering semicolons, tabs, multiline abstract strings, factor-to-character coercions, and chained end-to-end pipelines into `biblioshiny`.
- **SciELO JATS XML parser `read_scielo_jats()`**: Implemented comprehensive parser for full-text and metadata XMLs complying with NLM/JATS specifications. Supports single `.xml` files, folders, and `.zip` archives. Extracts core article metadata (`AU`, `TI`, `SO`, `PY`, `AB`, `DE`, `DI`, `SN`, `VL`, `IS`, `BP`, `EP`, `C1`) and parses cited references from `<ref-list>` (`<element-citation>` and `<mixed-citation>`) into the canonical `CR` tag, enabling network cocitation and bibliographic coupling in `bibliometrix`.
- **Stress testing and edge-case resilience**: Added comprehensive test suites using real-world SciELO JATS XML articles and OpenAlex-harvested datasets. Hardened parsing for escaped XML entities in titles, journals, and citations, supported institutional and collaborative authors (`<collab>`), isolated primary metadata from multilingual translations in `<sub-article>`, and ensured graceful handling of articles without cited references.
- **Analytical integration test suite with `bibliometrix`**: Added functional test suites executing core analytical and network algorithms directly from `bibliometrix` (`biblioAnalysis`, `summary`, `biblioNetwork` for reference co-citation, author collaboration, keyword co-occurrences, and author bibliographic coupling) over datasets produced by `read_scielo_jats` and `read_scielo`.
