# bibliolatam 0.1.0.9000

- **Initial repository structure and governance**: Scaffolded package infrastructure, dual licensing (GPL-3.0 for code and CC BY-NC-SA 4.0 for scientometric fixtures), and standard BRAN Org community health files.
- **R CMD check hygiene and build flags**: Added `.Rbuildignore` to strip top-level repo metadata (`.github/`, docs, changelog, licensing files) from the R build tarball, preventing non-standard file warnings.
- **Base converter `as_bibliometrix()`**: Introduced canonical converter enforcing the `bibliometrixDB` class contract. Validates essential fields (`AU`, `TI`, `SO`, `PY`), coerces numerical tags (`PY`, `TC`), generates canonical standard reference tags (`SR`, `SR_FULL`, `JI`, `J9`) required by `cocMatrix()` and network routines, and injects standard WoS-like tags missing in source files as `NA` without data fabrication.
- **SPELL / ANPAD parser `read_spell()`**: Added resilient parser for Brazilian administration and economics exports (CSV). Supports automatic delimiter detection (`;`, `,`, `\t`), encoding fallback (UTF-8 to Latin-1), and normalizes author names to the standard WoS format (`SOBRENOME INICIAIS; ...`).
- **GUI exporter `export_biblioshiny()`**: Added utility to serialize converted collections into `.RData` files packaging canonical object `M`. Enables direct import via `biblioshiny`'s *Data -> Load bibliometrix RData* menu without script execution.
- **SciELO tabular parser `read_scielo()`**: Added parser for SciELO export files (CSV). Supports Portuguese, Spanish, and English column headers, normalizes multilingual author entries into the standard WoS format (`SOBRENOME INICIAIS; ...`), and maps core metadata (`TI`, `AU`, `SO`, `PY`, `AB`, `DE`, `DI`, `SN`).
- **Robust author normalizer `normalize_authors()`**: Extracted standalone author normalization engine with support for Brazilian generational suffixes (`Junior`, `Filho`, `Neto`, `Sobrinho`), lowercase particles (`da`, `de`, `del`, `van`), and single-name entities.
- **Expanded test coverage for edge cases**: Added dedicated test suites covering semicolons, tabs, multiline abstract strings, factor-to-character coercions, and chained end-to-end pipelines into `biblioshiny`.
- **SciELO JATS XML parser `read_scielo_jats()`**: Implemented comprehensive parser for full-text and metadata XMLs complying with NLM/JATS specifications. Supports single `.xml` files, folders, and `.zip` archives. Extracts core article metadata (`AU`, `TI`, `SO`, `PY`, `AB`, `DE`, `DI`, `SN`, `VL`, `IS`, `BP`, `EP`, `C1`) and parses cited references from `<ref-list>` (`<element-citation>` and `<mixed-citation>`) into the canonical `CR` tag, enabling network cocitation and bibliographic coupling in `bibliometrix`.
- **Stress testing and edge-case resilience**: Added comprehensive test suites using real-world SciELO JATS XML articles and OpenAlex-harvested datasets. Hardened parsing for escaped XML entities in titles, journals, and citations, supported institutional and collaborative authors (`<collab>`), isolated primary metadata from multilingual translations in `<sub-article>`, and ensured graceful handling of articles without cited references.
- **Analytical integration test suite with `bibliometrix`**: Added functional test suites executing core analytical and network algorithms directly from `bibliometrix` (`biblioAnalysis`, `summary`, `biblioNetwork` for reference co-citation, author collaboration, keyword co-occurrences, and author bibliographic coupling) over datasets produced by `read_scielo_jats` and `read_scielo`.
- **SciELO JATS automated downloader `download_scielo_jats()`**: Added automated download engine to retrieve raw JATS XML documents directly from official SciELO endpoints using DOIs, classic PIDs, or article URLs. Follows HTTP redirection chains using base R networking with retry resilience on transient server errors, validates XML payload integrity, and supports direct parsing into `bibliometrixDB` objects or returning local XML paths.
- **SciELO JATS language extraction (`LA`)**: Enhanced `read_scielo_jats()` to extract primary article language directly from the root `<article>` `xml:lang` attribute and normalize language codes into standard uppercase descriptors (`ENGLISH`, `PORTUGUESE`, `SPANISH`).
- **BDTD / Oasisbr parser `read_bdtd()` & `read_oasisbr()`**: Added resilient parser for Brazilian thesis and dissertation records exported from IBICT's BDTD and Oasisbr portals (CSV/TSV). Maps institutional affiliations and graduate programs to `SO`, advisors to `RP`, document types to `THESIS` or `DISSERTATION`, normalizes author names via `normalize_authors()`, maps persistent handles/URIs to `UT`, and standardizes languages (`LA`).
- **Biblioshiny SciELO UI & Server integration (`scieloUI`, `scieloServer`, `bibliolatamInfoUI`)**: Added interactive Shiny interface module for `biblioshiny`. Introduces a dedicated "Bibliolatam" menu section with submenus for SciELO and an informative "Info & About" documentation tab detailing regional coverage, FAIR principles, and governance. SciELO panel supports online automated retrieval by DOIs/PIDs with live progress, offline JATS XML and CSV parsing, diagnostic cards, and one-click injection into `values$M`.
- **Biblioshiny BDTD UI integration (`bdtdUI`, `bdtdServer`)**: Added dedicated "BDTD" submenu under "Bibliolatam" in `biblioshiny`. Supports online query retrieval via the official IBICT VuFind Search REST API, local CSV/TSV upload, degree filtering (Theses vs Dissertations), preview statistics (works, theses/dissertations ratio, institutions count, timespan), and seamless injection into the app's analytical reactive workflow.
- **Biblioshiny Oasisbr UI integration (`oasisbrUI`, `oasisbrServer`)**: Added dedicated "Oasisbr" submenu under "Bibliolatam" in `biblioshiny` for multidisciplinary Brazilian open-access production. Supports online query search, local CSV/TSV upload, document type filtering (`DT`), repository sources summary, and reactive injection into `values$M`.
- **VuFind Search REST API download engine (`download_bdtd`, `download_oasisbr`)**: Implemented automated client for IBICT's VuFind Search API supporting query pagination, author normalization, document type mapping, and conversion into canonical `bibliometrixDB` objects.
- **Cross-Database Deduplication & Merge engine (`merge_bibliolatam`)**: Added intelligent entity resolution combining heterogeneous regional datasets (e.g. SciELO + Oasisbr or SciELO + SPELL). Deduplicates via canonical DOI cleaning and fuzzy title matching (Levenshtein distance), and fuses complementary metadata fields (`CR`, `AB`, `DE`, `DI`).
- **Redalyc / AmeliCA parser & Shiny panel (`read_redalyc`, `redalycUI`, `redalycServer`)**: Added support for Ibero-American diamond open-access journals. Parses BibTeX (`.bib`), RIS (`.ris`), and CSV exports with Hispanic compound author surname normalization.
- **Bibliolatam Merge UI module (`bibliolatamMergeUI`, `bibliolatamMergeServer`)**: Added interactive collection merge interface in `biblioshiny` with deduplication diagnostics, preview table, and one-click injection into `values$M`.
- **SciELO Crossref search engine (`download_scielo_search`)**: Added automated online query retrieval for SciELO journal articles using the public Crossref REST API filtered by SciELO's DOI prefix (`10.1590`), bypassing portal rate limits with full bibliographic tag mapping.
- **LA Referencia REST API client (`download_lareferencia`)**: Added automated query search and metadata parser for LA Referencia (connecting 12 Latin American national repository networks) using the VuFind REST API v1.
- **Unified Latin American Omnisearch engine (`omnisearch_bibliolatam`, `omnisearchUI`, `omnisearchServer`)**: Introduced federated multi-source discovery engine querying SciELO, BDTD, Oasisbr, and LA Referencia simultaneously. Features automated entity resolution via `merge_bibliolatam()`, summary KPI cards, and single-click injection into `values$M` matching the OpenAlex workflow.
- **API-level year filtering for Latin American discovery**: Added `years` parameter across `download_bdtd()`, `download_oasisbr()`, `download_lareferencia()`, `download_scielo_search()`, and `omnisearch_bibliolatam()`. Filters publications at the API endpoint level via Crossref `from-pub-date`/`until-pub-date` and VuFind Solr `publishDate:[start TO end]`, minimizing network payloads and query quotas.
- **Cited References (`CR`) enrichment for SciELO (`enrich_references`)**: Added optional `enrich_references` flag in `download_scielo_search()` and `omnisearch_bibliolatam()` to retrieve NLM/JATS XML full texts via `download_scielo_jats()` and reconstruct references into the `CR` tag, unlocking co-citation and bibliographic coupling in `bibliometrix`.
- **Direct CSV and .RData exports in Biblioshiny Omnisearch**: Added dedicated export buttons and handlers (`omniDownloadCSV`, `omniDownloadRData`) within the Omnisearch Shiny panel to download harmonized datasets directly as CSV or bibliometrix-ready `.RData`.
